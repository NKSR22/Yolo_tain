LAB 10 · Dataset + Colab

เตรียมชุดข้อมูลและเทรน YOLO บน Google Colab

รับภาพจาก Lab 9 → ให้โมเดลเสนอกรอบและตรวจแก้ → เทรนบน Colab

สิ่งที่ต้องเข้าใจก่อน

โฟลเดอร์คลาสจาก GUI ใน Lab 9 ยังไม่ใช่ label สำหรับ Object Detection Notebook จะเสนอ Bounding Box จากโมเดล YOLO-World ให้ตรวจแก้ใน Colab แล้วสร้าง label และชุดข้อมูล YOLO ให้ก่อนเทรน ผลลัพธ์เป็น best.pt

1. เตรียมภาพและ ZIP

  1. คัดภาพที่ชัดและไม่ซ้ำจากโฟลเดอร์ Lab9_ConveyorCapture\captured_images\<class>\
  2. รัน .\Lab9_ConveyorCapture\scripts\make_zip.bat จะได้ Lab9_ConveyorCapture\conveyor_images.zip แล้วอัปโหลดไปที่ชั้นบนสุดของ Google Drive (My Drive)

ให้มีหลายชิ้นงาน มุม ตำแหน่ง และสภาพแสงต่อคลาส ไม่ใช่ถ่ายวัตถุเดิมซ้ำหลายเฟรม

2. เปิด Colab และตรวจ Bounding Box

  1. ใน Colab เลือก File → Upload notebook แล้วเลือก colab_train_conveyor.ipynb จาก repository
  2. เลือก Runtime → Change runtime type → GPU แล้วรันเซลล์จากบนลงล่าง อนุญาตให้เชื่อมต่อ Google Drive
  3. ใช้โหมด raw และตรวจตำแหน่ง ZIP ในเซลล์ตั้งค่า ชื่อคลาสจาก Lab 9 เป็นภาษาอังกฤษอยู่แล้ว และถูกใช้เป็นคำค้นให้ YOLO-World หาวัตถุ ถ้าชื่อคลาสไม่ได้บอกว่าวัตถุหน้าตาเป็นอย่างไร (เช่น part_a) ให้กำหนด PROMPT_OVERRIDES เช่น {"part_a": "small metal bracket"}
  4. ตรวจกรอบทุกภาพ: โมเดลเสนอกรอบตามคลาสของโฟลเดอร์ภาพนั้น ให้เพิ่มกรอบของวัตถุคลาสอื่นที่มีในภาพเอง เลือกคลาส ลากเพิ่ม/แก้/ลบกรอบ แล้วกด Submit หากภาพไม่มีวัตถุจริง ให้เลือกช่องยืนยันภาพว่างก่อน Submit
  5. Skip จะข้ามโดยไม่บันทึกผลตรวจ ต้องกลับมาตรวจและ Submit ให้ครบก่อนเทรน

ผลตรวจบันทึกลง Drive ใน conveyor_reviews และสามารถกลับมาทำต่อได้โดยใช้ ZIP และการตั้งค่าเดิม หากแก้ prompt หรือเปลี่ยน ZIP จะเริ่มชุดผลตรวจใหม่

3. สร้าง Dataset และเทรน

  1. เมื่อกด Submit ครบทุกภาพ ให้รันเซลล์สร้างชุดข้อมูล ระบบจะแบ่ง Train/Validation และสร้าง YOLO labels ให้อัตโนมัติ
  2. รันเซลล์ตรวจชุดข้อมูล เทรน และประเมินผลตามลำดับ

หากมีชุดข้อมูล YOLO ที่ทำ label และแบ่ง Train/Val ไว้แล้ว สามารถเลือกโหมด prepared และระบุ ZIP แทนได้

กรอบอัตโนมัติอาจพลาดวัตถุหรือคลาส โดยเฉพาะชิ้นงานเฉพาะทางและความแตกต่างแบบดี/เสีย ต้องตรวจทุกภาพ อย่าให้ภาพซ้ำหรือเกือบซ้ำกระจายอยู่ทั้ง Train และ Val เพราะตัวเลขประเมินอาจดูดีเกินจริง ตรวจ results.csv และผล validation ประกอบ อย่าตัดสินคุณภาพจากค่าเดียว

ผลลัพธ์และขั้นถัดไป

โมเดล best.pt และผลฝึก results.csv จะอยู่ใน Google Drive ที่ conveyor_training\<run name>\ ดาวน์โหลด best.pt แล้วนำไปทดสอบภาพ/วิดีโอบนคอมตาม Lab 11
