LAB 11 · Windows inference

ทดสอบโมเดลที่เทรนจาก Colab บนคอม

ตรวจว่า best.pt โหลดได้และตรวจจับวัตถุในภาพจริงก่อนแปลงไป Raspberry Pi

1. วางโมเดลและเตรียมเครื่อง

  1. ดาวน์โหลด best.pt จาก Drive หลังจบ Lab 10
  2. คัดลอกไปไว้ที่ Lab11_WindowsTesting\best.pt
  3. เปิด PowerShell ที่ root ของ repository ตรวจว่ามี venv จาก Lab 0

2. รันกับภาพหรือวิดีโอ

ส่ง path ของภาพหรือวิดีโอเป็น argument ให้สคริปต์ เช่น:

.\Lab11_WindowsTesting\scripts\run_test.bat "C:\path\to\an-unseen-test-image.jpg"
.\Lab11_WindowsTesting\scripts\run_test.bat "C:\data\conveyor\test clip.mp4"

เปลี่ยนตัวอย่าง path ให้เป็นไฟล์จริงบนเครื่อง ผลภาพที่วาดกรอบแล้วจะอยู่ใน runs\detect\lab11_custom_test\ ตรวจชื่อคลาส ความถูกต้องของกรอบ และกรณีที่วัตถุถูกพลาดหรือทายผิด

ภาพทดสอบที่ดีที่สุดคือภาพจากสายพานจริงที่ไม่ได้อยู่ใน ZIP ที่ใช้เทรน เปิด GUI ของ Lab 9 อีกครั้ง ตั้ง Save under เป็นโฟลเดอร์ใหม่ เช่น C:\data\lab11_test แล้วเก็บภาพชุดใหม่ไว้ทดสอบ

3. ทดสอบสดกับกล้องบนสายพาน

ใส่หมายเลขกล้องแทน path จะเปิดหน้าต่างแสดงผลสด (ไม่บันทึกไฟล์) ปิดด้วย q หรือ Ctrl+C:

.\Lab11_WindowsTesting\scripts
un_test.bat 0

เปิดสวิตช์สายพาน วางวัตถุแต่ละคลาสให้วิ่งผ่าน กลับทิศแล้วลองอีกรอบ ดูว่ากรอบติดตามวัตถุได้ต่อเนื่องตลอดทางหรือหลุดบางช่วง ช่วงที่หลุดบ่อยคือช่วงที่ไม่ควรวางเส้นนับใน Lab 12

ถ้าขึ้น can't grab frame แล้วจบทันที ให้รันคำสั่งเดิมอีกครั้ง เว็บแคม USB บางรุ่นบน Windows อ่านเฟรมแรกไม่สำเร็จเป็นบางครั้ง (ตอนทดสอบเจอ 2 ครั้งจากการเปิดกล้องประมาณ 7 ครั้ง)

ทดสอบด้วยภาพที่ไม่ได้ใช้ฝึก โดยเฉพาะภาพจากสภาพแสง/ตำแหน่งที่ต่างกัน ตรวจทั้งวัตถุที่มีและไม่มีในภาพ อย่าใช้ภาพ Train ชุดเดิมเป็นหลักฐานว่าโมเดล generalize ได้

ผลลัพธ์และขั้นถัดไป

เมื่อโมเดลทำงานและผลบนภาพทดสอบน่าเชื่อถือแล้ว ให้ใช้ไฟล์ best.pt เดิมทำ ONNX และนำไปรันบน Raspberry Pi ตาม Lab 12
