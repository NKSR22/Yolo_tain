LAB 9 · Image collection

เก็บภาพวัตถุจากสายพานที่วิ่งอยู่

คอม Windows + เว็บแคม · สายพานเปิด/กลับทิศด้วยสวิตช์ ไม่มี MCU ควบคุม

เป้าหมายและขอบเขต

สายพานวิ่งเองตลอดเมื่อเปิดสวิตช์ โปรแกรมนี้แค่ดูกล้องอย่างเดียว ผู้เรียนวางวัตถุทีละชิ้นบนสายพาน เมื่อวัตถุเคลื่อนมาถึงกลางกรอบที่วาดไว้ โปรแกรมจะบันทึกภาพเต็มเฟรมหนึ่งใบ แล้วรอจนวัตถุนั้นออกไปก่อนจึงพร้อมถ่ายชิ้นถัดไป ดังนั้นวัตถุหนึ่งชิ้นที่วิ่งผ่านจะได้ภาพหนึ่งใบ

ชื่อคลาสที่พิมพ์ในโปรแกรมจะกลายเป็นชื่อโฟลเดอร์ และกลายเป็นชื่อคลาสของ YOLO ใน Lab 10 Lab นี้ยังไม่ได้ทำ Bounding Box

Lab9 เก็บภาพ (Windows) → Lab10 ตีกรอบ + เทรน (Colab) → Lab11 ทดสอบ best.pt (Windows) → Lab12 ONNX + นับจำนวนบน Pi

1. จัดกล้องให้นิ่ง

  1. ยึดกล้องให้มองสายพานจากตำแหน่งเดียวกับที่จะใช้ตอนรันจริงบน Pi ใน Lab 12 ภาพตอนเทรนกับตอนใช้งานยิ่งเหมือนกัน โมเดลยิ่งแม่น
  2. วางกล้องให้สายพานวิ่งซ้าย↔ขวาในภาพ (Lab 12 นับด้วยเส้นแนวตั้งเป็นค่าเริ่มต้น)
  3. กล้องต้องไม่ขยับระหว่างเก็บภาพ โปรแกรมตรวจจับวัตถุจากความต่างกับภาพพื้นหลัง กล้องที่สั่นจะทำให้ทั้งกรอบดูเหมือนมีการเคลื่อนไหว
  4. เปิดไฟให้สว่างคงที่ หลีกเลี่ยงแสงแดดที่เปลี่ยนไปเรื่อย ๆ

2. เปิดโปรแกรม

จาก PowerShell ที่โฟลเดอร์หลักของ repository:

.\Lab9_ConveyorCapture\scripts\run_capture_gui.bat

ถ้าใช้ชุด ZIP แบบ portable (ไม่มี venv จาก Lab 0) ให้ดับเบิลคลิก scripts\run_capture_gui_portable.bat แทน ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อติดตั้ง opencv-python และ Pillow

3. ตั้งค่าและเริ่มเก็บภาพ

  1. กด Open camera (ถ้าเปิดผิดตัว เปลี่ยน Camera index เป็น 1, 2 …)
  2. กด Draw capture area แล้วลากกรอบคร่อมสายพานตรงกลางภาพ ให้กว้างกว่าวัตถุชิ้นใหญ่สุดพอสมควร
  3. พิมพ์ Class name เป็นภาษาอังกฤษ เช่น bottle, red_cap (ใช้ได้เฉพาะ A–Z, 0–9, _, -)
  4. เปิดสวิตช์สายพาน ปล่อยให้วิ่งเปล่า ๆ แล้วกด Start auto capture โปรแกรมจะเรียนรู้หน้าตาสายพานเปล่าประมาณ 45 เฟรม (กรอบเป็นสีเหลือง) ห้ามมีวัตถุในกรอบช่วงนี้
  5. วางวัตถุบนสายพานทีละชิ้น เว้นระยะระหว่างชิ้น เมื่อวัตถุถึงกลางกรอบ กรอบจะเป็นสีแดงและบันทึกภาพหนึ่งใบ
  6. เปลี่ยนคลาส: กด Stop auto capture → แก้ Class name → Start auto capture ใหม่

ภาพถูกบันทึกที่ Lab9_ConveyorCapture\captured_images\<class>\ แถวล่างของหน้าต่างแสดงจำนวนภาพต่อคลาสที่เก็บในรอบนี้

ปุ่ม/ค่าใช้ทำอะไร
Motion threshold %วัตถุต้องกินพื้นที่ในกรอบอย่างน้อยกี่ % จึงนับว่ามีวัตถุ ค่าเริ่มต้น 2.0 ดูตัวเลข motion ที่แถบสถานะตอนสายพานวิ่งเปล่า ๆ ควรใกล้ 0% ถ้าสูงเกิน threshold (ลายหรือรอยต่อสายพาน) ให้เพิ่ม threshold
Capture now (Space)ถ่ายทันทีหนึ่งใบโดยไม่รอการตรวจจับ ใช้เก็บภาพมุมแปลก ๆ หรือภาพที่ auto พลาด
สีกรอบเขียว = ยังไม่เริ่ม · เหลือง = กำลังเรียนรู้/รอวัตถุ · แดง = มีวัตถุอยู่กลางกรอบ

4. เก็บภาพให้ได้ชุดข้อมูลที่ดี

  • อย่างน้อย 50 ภาพต่อคลาส จากชิ้นงานหลายชิ้น ไม่ใช่ชิ้นเดียววนซ้ำ 50 รอบ
  • เปลี่ยนตำแหน่งบนสายพาน (ชิดขอบซ้าย/กลาง/ขวา) และหมุนวัตถุหลายท่า
  • กลับทิศสายพานด้วยสวิตช์แล้วเก็บอีกชุด ตัวตรวจจับไม่สนทิศ ไม่ต้องตั้งค่าอะไรเพิ่ม และโมเดลจะได้เห็นวัตถุทั้งสองทิศ
  • เปิดโฟลเดอร์ดูภาพ ลบภาพเบลอ ภาพที่วัตถุตกขอบ และภาพที่ไม่มีวัตถุ

Troubleshooting

อาการสาเหตุ / วิธีแก้
ภาพในหน้าต่างดำทั้งจอ แต่ไม่มี errorแอนตี้ไวรัสบล็อกกล้อง (เช่น Kaspersky Webcam Protection) ต้องอนุญาต venv\Scripts\python.exe
Camera frame read failedกล้องถูกโปรแกรมอื่นใช้อยู่ (Teams, Zoom, Camera app) ปิดโปรแกรมนั้น แล้วกด Open camera ใหม่
ถ่ายรัว ๆ ทั้งที่ไม่มีวัตถุกล้องสั่น หรือลายสายพานถูกนับเป็นวัตถุ ยึดกล้องให้แน่น และเพิ่ม Motion threshold
วัตถุวิ่งผ่านแต่ไม่ถ่ายวัตถุเล็กเกินเมื่อเทียบกับกรอบ ให้วาดกรอบเล็กลง หรือลด threshold · หรือวัตถุสีกลืนกับสายพาน
ชิ้นเดียวได้สองภาพเกิดเมื่อวัตถุหยุดหรือถอยกลับกลางกรอบ ลบภาพซ้ำทิ้ง
Class name ถูกปฏิเสธใช้ภาษาไทยหรือเว้นวรรคไม่ได้ เพราะชื่อนี้ใช้เป็น prompt ภาษาอังกฤษให้ YOLO-World ใน Lab 10 และ OpenCV บน Pi วาดตัวอักษรไทยไม่ได้
