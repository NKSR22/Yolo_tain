# YOLO Training Labs

ชุดแบบฝึก Lab 0-12 เพื่อเตรียมความพร้อมนักศึกษาก่อนทำโครงงาน YOLO Object Detection

เปิด `index.html` ด้วยเบราว์เซอร์เพื่อดูสารบัญและลิงก์ไปคู่มือของแต่ละ Lab

**เริ่มต้นที่ `Lab0_Setup` ก่อนเสมอ** แต่ละ Lab ใช้ผลลัพธ์ต่อจาก Lab ก่อนหน้าเป็นเส้นเดียวไม่ขาด

## หมายเหตุสำหรับคนที่มาแก้ไขต่อ

- **ห้ามเขียนคู่มือจากการอ่านโค้ดอย่างเดียว ต้องรันจริงทุกสคริปต์** บั๊กที่เจอมาทั้งหมดในรีโปนี้ ไม่มีสักตัวที่มองออกจากการอ่านโค้ดเฉย ๆ
- **ข้อความที่สคริปต์พิมพ์ออกจอต้องเป็น ASCII** — console ที่ไม่ใช่ codepage ไทยจะแสดงภาษาไทยเป็น `?` และตัวเรนเดอร์ภาพประกอบ (`docs/shoot.py`) วาดสระ/วรรณยุกต์ไทยไม่ได้ ภาษาไทยให้อยู่ในคอมเมนต์และในคู่มือ
- **`.gitattributes` บังคับ `*.sh` เป็น LF ไว้แล้ว** อย่าไปแก้ ถ้าไฟล์ `.sh` กลายเป็น CRLF บน Pi มันจะพังทุกบรรทัดพร้อมกับทำให้ `set -e` ไม่ทำงาน แล้วสคริปต์จะจบด้วย exit 0 ทั้งที่ล้มเหลว
- เก็บภาพประกอบด้วย `docs/shoot.py` ทุกกรณี รวมที่ `docs/images/` เท่านั้น
