YOLO Object Detection: จากศูนย์ถึงโครงงานจริง

📚 11 Lab (Lab 0-10)⏱ รวมประมาณ 30-40 ชั่วโมง🖥 Windows + Raspberry Pi

📖 เกี่ยวกับคอร์สนี้

ชุดแบบฝึกนี้ออกแบบมาเพื่อเตรียมความพร้อมนักศึกษาก่อนเริ่มทำโครงงานที่ใช้ YOLO Object Detection ตั้งแต่การเตรียมเครื่อง การ Train โมเดล การสร้าง Dataset เอง ไปจนถึงการนำโมเดลไปใช้งานจริงบน Raspberry Pi ร่วมกับ AI HAT และระบบ Conveyor + GPIO

แต่ละ Lab มีโฟลเดอร์แยกของตัวเอง พร้อมสคริปต์สำหรับรันงาน (.bat สำหรับ Windows, .sh สำหรับ Raspberry Pi ใน Lab 7-9) และคู่มือฉบับเต็มแบบ HTML
