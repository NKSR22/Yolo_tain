YOLO Object Detection: จากศูนย์ถึงโครงงานจริง

📚 13 Lab (Lab 0-12)⏱ รวมประมาณ 30-40 ชั่วโมง🖥 Windows + Raspberry Pi

📖 เกี่ยวกับคอร์สนี้

ชุดแบบฝึกนี้ออกแบบมาเพื่อเตรียมความพร้อมนักศึกษาก่อนเริ่มทำโครงงานที่ใช้ YOLO Object Detection ตั้งแต่การเตรียมเครื่อง การ Train โมเดล การสร้าง Dataset เอง ไปจนถึงการนำโมเดลไปใช้งานจริงบน Raspberry Pi ร่วมกับ AI HAT และนับวัตถุบนสายพานลำเลียง

แต่ละ Lab มีโฟลเดอร์แยกของตัวเอง พร้อมสคริปต์สำหรับรันงาน (.bat สำหรับ Windows, .sh สำหรับ Raspberry Pi ใน Lab 7, 8 และ 12) และคู่มือฉบับเต็มแบบ HTML

▶️ วิธีรันสคริปต์ .bat

ดับเบิลคลิกที่ไฟล์ได้เลย หรือพิมพ์ใน Terminal โดยใส่ .\ นำหน้าชื่อไฟล์เสมอ:

cd Lab1_TrainReadyDataset\scripts
.\train.bat

ถ้าพิมพ์ train.bat เฉย ๆ ใน PowerShell (Terminal ค่าเริ่มต้นของ Windows Terminal และ VS Code — บรรทัดคำสั่งขึ้นต้นด้วย PS) จะขึ้น error ว่า is not recognized as the name of a cmdlet... เพราะ PowerShell ไม่รันไฟล์ในโฟลเดอร์ปัจจุบันโดยไม่ระบุ path — ไม่ใช่ว่าไฟล์หายหรือติดตั้งไม่ครบ
